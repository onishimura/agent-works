# Use one unit table in duration.py

## Goal
`parse_duration` and `format_duration` each list the units h, m and s. Keep the units in one table, so that a new unit needs only one change.

## Acceptance criteria
- [ ] `duration.py` defines each unit and its size in one table, and both functions use it.
- [ ] `parse_duration` and `format_duration` give the same results as before.
- [ ] The tests of both functions stay.

## Out of scope
- New units.
